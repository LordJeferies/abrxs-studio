# Content creation flows

Abrxs Studio does not force every piece through every workspace.

## Long-form recording → many clips

```text
Canter → Content/Fichas → Editorial/Geómetra → Canter cuts → Vision assets → Dresser batch → Review → Publisher
```

## Idea → talking-head

```text
Brand → Content → Ficha → Editorial/Geómetra → Record → Canter → Vision as needed → Dresser → Review → Publisher
```

## Faceless

```text
Brand → Content → Ficha → Geómetra/Lienzo → Vision scene/shot plan → Dresser → Review → Publisher
```

## Carousel / graphic

```text
Brand → Content → Ficha → Editorial/Geómetra → Vision → Review → Publisher
```

Dresser is optional unless the carousel becomes an animated video.

## Text post / newsletter

```text
Brand → Content → Ficha → Review → Publisher
```

Vision is optional for cover/illustration/graphics.

## Existing finished video → dress only

```text
Video → Dresser → Review → Publisher
```

A full Ficha is optional and can be attached later.

## Existing image → improve / layer / animate

```text
Asset → Vision → asset version / layer package → Dresser if motion is required
```

## Fast XRoll

```text
visual idea → Vision Quick Creator → prompt/generate → save asset → Dresser slot
```

## Podcast batch

```text
Podcast → Canter source truth → 20 approved fichas → Canter batch cuts → Dresser batch profile → Review grid → Publisher
```
