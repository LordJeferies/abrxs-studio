# Abrxs Vision · Third-Party Notices

Abrxs Vision V2.6 includes original ABRAXAS product logic and UI, plus selected interaction ideas and visual reference assets derived from or linked to third-party open-source projects.

## Open Generative AI

Repository: `Anil-matcha/Open-Generative-AI`

Used in Vision V2.6 for:

- interaction reference for the selectable `Cinema Columns` camera-configuration view;
- selected cinema reference assets used as visual examples for camera, aperture and special-lens choices.

Vision does not copy Open Generative AI branding. The ABRAXAS state model, Source Truth workflow, recommendation engine, camera-scene simulator, Prompt Monitor, Learn integration and target compilation remain ABRAXAS implementations.

## Unsplash-hosted photographic examples

Some `Photo Reference` examples are loaded from Unsplash-hosted image URLs and are used as contextual photographic examples, not as physically exact simulations. `Camera View` is the controlled technical comparison surface for focal length, shot scale, camera height/angle, aperture/focus and motion relationships.
