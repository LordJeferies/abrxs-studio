# Abrxs Vision V2.6 · Director Intelligence

V2.6 preserves the V2.5 Director engine and makes a new Director Intelligence workspace the default experience.

## Canonical flow

```text
SOURCE TRUTH
   ↓
SOURCE INTELLIGENCE
   ↓
VISION UNDERSTANDING
   ↓
SUGGESTED DIRECTION
   ↓
VISUAL COMPARE / REFERENCE ENGINE
   ↓
DIRECTOR
   ↓
ABRAXAS PRODUCTION PROMPT
   ↓
TARGET COMPILER
```

## Added in V2.6

- local Source Truth analysis;
- explainable per-category recommendations;
- reason + tradeoff + alternatives + confidence;
- Source Truth vs Direction conflict warnings;
- large same-scene comparison workspace;
- Grid/compare-style option rail and Learn explainer;
- Prompt Anatomy colour legend;
- clickable Prompt Anatomy tokens that navigate back to Director categories;
- contextual `What do I do here?` help;
- `What it resembles` onboarding using Higgsfield, Magnific, Creativly and OpenChatCut as mental models;
- V2.6 PWA/Tauri versioning;
- V2.6 CI, Pages and release gates.

## Reference honesty

The built-in programmatic comparison is labeled `EDUCATIONAL APPROXIMATION`. It is not presented as physically exact optics. Curated photographic, rendered, motion and Three.js reference packs can be added later without changing Director semantics.

## Decision doctrine

Vision proposes. The user applies. Source Truth remains separate from visual interpretation. No provider generation or spend should be triggered by recommendation logic.
