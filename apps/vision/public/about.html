PROMPT IMPROVER · CINEMA DIRECTOR · PRODUCTION COMPILER

Texto base. Dirección visual. Prompt ejecutable.

Abrxs Vision V2.5 convierte una idea, guion, prompt débil o ficha existente en una dirección visual profesional. El usuario conserva Source Truth y decide cómo debe verse mediante referencias visuales, presets y controles explicados. Vision compila esas decisiones en un prompt ABRAXAS listo para adaptarse a imagen, video o XRoll.

Conecta tus modelos

Assistant y Generator son roles independientes. Además de las conexiones incorporadas, V2.5 permite registrar providers personalizados.

Built-in

NVIDIA · Gemini · ComfyUI

Desktop puede usar Keychain, CLI y localhost. La PWA usa Cloud Gateway cuando necesita secretos persistentes.

Custom LLM

OpenAI / Anthropic compatible

Configura Base URL, modelo, endpoints y capabilities. Las keys personalizadas del navegador son de sesión por defecto.

Generic REST

Imagen / video futuros

Puede registrarse para routing, pero la ejecución permanece bloqueada hasta que exista un adapter real y validado.

Vision no simula generación ni gasta créditos sin confirmación. Un provider “prepared” no equivale a un provider “implemented and validated”.
