DIRECTOR STUDIO · PROMPT COMPILER · VISUAL PRODUCTION

De una idea a una dirección visual ejecutable.

Abrxs Vision V2 crea y mejora prompts, actualiza fichas del Geómetra/Content Creator, diseña XRolls por capas, genera storyboards y carruseles, audita decisiones visuales y compila la misma intención para distintos modelos. El core funciona offline; la IA y la generación se habilitan sólo cuando existe un provider real.

Qué incluye V2

Prompt Studio

Crear o mejorar

Construcción desde cero, Prompt Anatomy por bloques, ABRAXAS QA, Director Lock y compilers específicos por target.

Copilot

Asistente visual

NVIDIA NIM o Gemini. Revisa el proyecto, propone cambios, referencias y patches aplicables; nunca modifica silenciosamente ni gasta créditos.

Ficha Intake

HTML · JSON · TXT

Detecta prompts embebidos, conserva el original, muestra contexto, prepara diffs y exporta una ficha actualizada.

XRoll Studio

2–8 layers

Master prompt, prompts por layer, alpha/parallax, motion spec, composite spec y handoff directo a Dresser.

Storyboard

Film grammar

Escenas y shots con cámara, focal, blocking, movimiento, continuidad y estructura narrativa verificable.

Learn

Cinema Playground

Explica focales, framing, movimiento e iluminación con referencias visuales y ayudas “?” para usuarios sin formación cinematográfica.

Carousel

Narrativa por slide

Hook, contexto, progresión, mecanismo y payoff con continuidad, text-safe areas y prompts por lámina.

Analyze

Referencia → estructura

Análisis local de metadata, paleta y muestreo; base para convertir referencias en Vision DNA, shots y storyboards.

MCP

Claude Code · Codex

Servidor stdio para compilar prompts, XRolls, storyboards, auditar, leer/parchear fichas y usar el Content Bridge desde agentes.

Cómo piensa Vision

El prompt no es la fuente de verdad. Vision conserva una especificación estructurada y la traduce al dialecto del modelo seleccionado.
