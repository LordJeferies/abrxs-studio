Pon el texto base. Vision dirige la imagen.

Abrxs Vision V2.5 convierte una idea, escena, guion corto, prompt débil o ficha existente en una dirección visual ejecutable. El usuario elige cámara, lente, foco, composición, iluminación, movimiento, look, atmósfera y FX mediante referencias visuales; Vision explica cada decisión y compila un prompt ABRAXAS de producción sin perder la intención original.

Qué cambia en V2.5

Source Truth

Texto base primero

Pega el texto del video, una descripción de escena o un prompt existente. Ese texto permanece como intención fuente mientras diriges la visual.

Cinema Director

Selecciona viendo

Decenas de decisiones visuales incluyen preview, nombre, efecto, sensación, casos de uso, advertencias y lenguaje de prompt.

Suggested Presets

Recetas sugeridas

Vision analiza el texto y recomienda combinaciones como Intimate Pressure, Human Documentary, Luxury Product, Decision XR, Beauty o Automotive.

Prompt Output

Prompt nuevo y mejorado

El compilador conserva la tesis y combina las decisiones elegidas con continuidad, restricciones, salida y lógica temporal para imagen, video o XR.

Copilot

IA como director asistente

NVIDIA NIM o Gemini pueden criticar, explicar y proponer cambios. Los patches se aplican sólo cuando el usuario los aprueba.

V2 preserved

No se perdió lo anterior

Fichas, XRoll Studio, Storyboard, Carousel, Content Bridge, providers, MCP, CLI, PWA, Tauri y Firebase siguen dentro del mismo sistema.

Director visual

La biblioteca se organiza por función cinematográfica y no por adjetivos genéricos.
