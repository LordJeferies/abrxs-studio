ABRXS VISION ART CREATOR · V2

Cómo usar Vision V2

Vision es el director visual entre una idea/ficha y la producción. Puedes crear prompts desde cero, mejorar prompts existentes, importar lienzos HTML/JSON/TXT, diseñar XR por capas y preparar storyboards/carruseles antes de conectar un generador.

01 · WELCOME

Empieza por el trabajo, no por la herramienta

La bienvenida pregunta si quieres crear/mejorar prompts, dirigir/generar imagen o vídeo, importar una ficha o construir un XRoll. Puedes cambiar de workspace después sin crear un proyecto nuevo.

02 · PROMPT STUDIO

Crea desde cero o mejora un draft

El prompt profesional declara función visual, sujeto/objeto, acción, escena, composición, cámara, luz, materiales, marca, continuidad, restricciones y output. “Premium/cinematográfico” por sí solo no cuenta como dirección.

03 · FICHA INTAKE

Actualiza los prompts dentro de fichas existentes

Ficha original

HTML / JSON / TXT con prompts, XR, slides y assets existentes.

→
Ficha Vision

Misma estructura; sólo los prompts aprobados cambian mediante patches.

  1. Importa una o varias fichas.
  2. Vision detecta prompts y muestra el contexto de cada pieza/asset.
  3. Edita manualmente o usa “Mejorar automáticamente”.
  4. Prepara el cambio, compara y exporta una copia nueva.

El HTML importado no se ejecuta. Vision lee su JSON embebido y conserva el lienzo original.

04 · XROLL STUDIO

Construye un XR como sistema de capas

Selecciona Auto o 2–8 layers. Vision genera prompt maestro, prompts independientes por capa, movimiento, parallax, orden de composición y handoff para Dresser.

BACKGROUND → MIDGROUND → SUBJECT → FOREGROUND → GRAPHICS
El texto exacto se mantiene editable cuando la ortografía importa.
05 · PRESETS

Guarda combinaciones, no párrafos

Un preset guarda formato, cámara, layers, motion, estilo, marca y política de texto. Luego Vision recompila la dirección para el target elegido. Puedes duplicar y derivar tus propios presets.

06 · CONTENT BRIDGE

El Creador de Contenidos puede usar Vision

Content Creator conserva tesis, source truth, estructura y prompt draft. Al seleccionar “Abrxs Vision”, usa el mismo core para obtener prompt profesional, QA y XRoll sin duplicar lógica.

Prompt engine ○ Basic ● Abrxs Vision
07 · DIRECTOR

No necesitas saber cine para dirigir

Cámara, focal, apertura, encuadre, ángulo, movimiento e iluminación tienen ayudas visuales. Los controles “?” deben explicar qué cambia, cómo se siente y cuándo conviene usarlo.

08 · TARGETS

Una intención, varios dialectos

ABRAXAS conserva la especificación canónica. Higgsfield/Seedance/Kling/Veo/NVIDIA/Gemini/ComfyUI reciben una traducción adaptada. I2V describe el cambio desde el primer frame en vez de repetir la imagen completa.

09 · STORYBOARD / CAROUSEL

Narrativa antes que decoración

Storyboard organiza escenas/planos y continuidad. Carousel organiza tesis, hook, contexto, progresión, mecanismo y payoff; cada slide tiene dirección visual y prompt autónomo.

10 · PWA / DESKTOP

La PWA es la app principal

La PWA funciona en navegador, iPhone, iPad y desktop y conserva el núcleo offline. Tauri es opcional para Keychain, archivos nativos, FFmpeg, vídeos grandes o procesos/modelos locales.

WORKFLOWS

Rutas rápidas

Idea → Prompt Studio → QA → Target Prompt → Generate/Export
Ficha HTML → Ficha Intake → Prompt diff → patch aprobado → HTML nuevo
Texto → XRoll Studio → layers → motion → Dresser
Content Creator → Abrxs Vision engine → VisionPackage → ficha/content actualizado
Idea narrativa → Storyboard → prompts por plano → frames/video
OFFLINE

Qué funciona sin APIs

Prompt core, Ficha Intake, patches, XRoll compiler/presets, Director, Carousel, Storyboard, proyectos e import/export. La generación cloud sólo se habilita cuando el provider real está configurado y declara la capacidad necesaria.
