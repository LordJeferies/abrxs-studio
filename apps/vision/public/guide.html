ABRXS VISION ART CREATOR · V0.3

Cómo usar Vision

Vision convierte una idea, texto de carrusel o referencia visual en una especificación de producción: función narrativa, cámara, luz, materiales, continuidad, restricciones y prompts ejecutables. El núcleo local funciona sin Internet.

01 · QUICK

Empieza con una frase concreta

  1. Describe qué quieres ver y qué debe comunicar.
  2. Selecciona un Vision DNA de marca.
  3. Ajusta cámara, encuadre o luz si importa para la idea.
  4. Copia Hero Frame Prompt, Motion Prompt o Production Spec.

Vision no convierte “premium/cinematográfico” en calidad por sí solo: cuanto más específica sea la acción o tensión, mejor será la dirección.

02 · DIRECTOR

Control cinematográfico con contexto

Cámara, lente, focal, apertura, encuadre, ángulo, movimiento e iluminación son decisiones. Las referencias visuales dentro de la app explican qué cambia cada parámetro para que puedas dirigir sin saber terminología de cine.

03 · PROMPT QA

La calidad se puede auditar

A

El compilador revisa idea, sujeto, acción, composición, cámara, luz, materiales, función visual, continuidad, restricciones de evidencia, marca y canvas. El score mide completitud de producción, no “gusto”.

04 · CAROUSEL

Carruseles como secuencia, no tarjetas

Cada slide recibe rol narrativo, dirección visual, prompt autónomo, jerarquía de texto, continuidad y negativos. Puedes pedir texto integrado, texto como capa o imagen limpia.

05 · STORYBOARD

Escenas y cobertura

Elige una gramática cinematográfica, escenas y planos. Vision propone rol, encuadre, focal, ángulo, movimiento, duración y transición. Úsalo como punto de partida: la historia manda sobre la plantilla.

06 · ANALYZE

Analiza localmente primero

Imágenes: dimensiones, aspecto, orientación, luminancia y paleta aproximada. Video: metadata y tiempos de muestreo. El análisis semántico profundo se añade mediante provider cuando sea útil.

07 · VISION DNA

Marca antes que decoración

Vision DNA fija cámara, luz, composición, paleta, textura, tipografía, continuidad y anti-patrones. Incluye JOC Editorial como preset específico; no lo aplica a otras marcas automáticamente.

08 · SETTINGS

Español o English

En Configuración puedes cambiar toda la interfaz entre español e inglés. La preferencia queda guardada localmente y funciona offline. El idioma de la interfaz y el idioma del prompt son decisiones separadas.

FLUJOS RECOMENDADOS

Frase → Quick → Prompt QA → Director → Production Spec → generador

Título + cuerpo por slide → Carousel → Prompt Pack → Canva / ChatGPT / generador
Imagen/video → Analyze → datos locales → provider sólo para interpretación semántica
Brand preset → Quick / Carousel / Storyboard → continuidad visual transversal
OFFLINE

Qué funciona sin Internet

Quick Creator, Prompt Director, Prompt QA, Director Lock, Vision DNA, Carousel, Storyboard, análisis local, proyectos e import/export. Los providers cloud sólo intervienen cuando una operación realmente necesita IA o generación.
