ABRXS VISION ART CREATOR · V0.2

Cómo usar Vision

Vision convierte una idea, texto de carrusel o referencia visual en decisiones cinematográficas estructuradas. El núcleo de prompts, carruseles, storyboards y análisis local funciona sin Internet. Los providers de IA se añaden después cuando necesitas análisis semántico o generación.

01 · QUICK

Empieza con una frase

  1. Escribe lo que quieres ver.
  2. Selecciona Vision DNA de marca.
  3. Ajusta cámara/luz si hace falta.
  4. Copia Hero Frame Prompt y Motion Prompt.

Úsalo cuando sólo necesitas un prompt de alta calidad rápidamente.

02 · DIRECTOR

Control cinematográfico

Define cámara, lente, focal, apertura, encuadre, ángulo, movimiento, iluminación, paleta y atmósfera. Director Lock evita que una mejora posterior cambie silenciosamente decisiones importantes.

03 · CAROUSEL

Carruseles

  1. Pega un slide por bloque.
  2. Elige estilo de diseño.
  3. Selecciona texto integrado, capa separada o imagen clean.
  4. Exporta el Prompt Pack.
04 · STORYBOARD

Escenas y cobertura

Elige una gramática cinematográfica, cantidad de escenas y shots por escena. Vision genera una estructura de cobertura con encuadre, focal, movimiento, duración y rol narrativo para cada shot.

05 · ANALYZE

Analiza media localmente

Selecciona una imagen o video. Vision calcula dimensiones, aspect ratio, orientación y, para imágenes, luminancia y paleta aproximada. Para video produce duración y tiempos recomendados de muestreo. El archivo no necesita salir del dispositivo.

06 · PROJECTS

Offline y proyectos

Los cambios se guardan en IndexedDB y además se pueden exportar como Abrxs-Vision-Project.json. Importa ese JSON para continuar en otro equipo o restaurar el proyecto.

FLUJOS RECOMENDADOS

Qué ruta usar según lo que quieras crear

Frase → Quick → Director → copiar prompt → generar donde quieras
Idea de película → Storyboard → copiar prompt por shot → generar frames/video
Título + cuerpo por slide → Carousel → Prompt Pack → Canva / ChatGPT / otro generador
Imagen/video existente → Analyze → usar datos locales → provider AI sólo si necesitas interpretación semántica
Brand preset → Quick / Carousel / Storyboard → coherencia visual transversal
OFFLINE

Qué funciona sin Internet

Quick Creator, Prompt Director, Director Lock, Vision DNA, Carousel Studio, Storyboard Studio, análisis local, proyectos y exportación de Prompt Packs. NVIDIA, Gemini, Higgsfield o ComfyUI sólo se usan cuando una operación necesita un provider.
