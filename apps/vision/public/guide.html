Cómo usar Director Studio.

Vision es un mejorador de prompts, director visual y compilador de producción. El flujo principal empieza con un texto normal: una idea, guion, descripción de escena, ficha o prompt débil. Después eliges visualmente cómo debe verse y Vision construye un prompt ABRAXAS de producción sin sustituir tu intención.

1. Empieza con Source Truth

En Director, pega el texto del video o la idea tal como realmente debe comunicarse. No hace falta saber de cine ni escribir un prompt perfecto.

Base

“Una persona compara tres propuestas, pero no puede decidir porque no tiene un criterio claro.”

→
Director

Vision conserva esa tesis y añade decisiones observables: cómo actúa, cómo se encuadra, qué focal usa, qué luz la modela y cómo termina el plano.

Source Truth manda. Una selección cinematográfica no debería reescribir la tesis; sólo define cómo se vuelve visible.

5. Vision Copilot

Copilot puede usar NVIDIA, Gemini o un LLM personalizado compatible. Ve el Source Truth, la selección de texto y la dirección V2.5. Devuelve recomendaciones y acciones estructuradas.

Usuario: “Mantén mi idea, pero dame más tensión sin volverlo thriller.” Vision: - conserva Source Truth - propone lens / light / movement concretos - explica por qué - devuelve patches V2.5 - no aplica nada automáticamente [ Aplicar ] ← siempre decisión del usuario

6. API keys y providers

Assistant y Generator son roles distintos. Settings incluye built-ins y providers personalizados.

Built-in

AI / local

NVIDIA NIM, Gemini/Gemini CLI, Vision Cloud Gateway y ComfyUI. Desktop puede usar Keychain y procesos locales.

Custom BYOK

Cualquier endpoint compatible

Registra OpenAI-compatible, Anthropic-compatible o Generic REST con base URL, modelo, endpoints y capabilities. Las custom keys del navegador son de sesión; no se escriben en GitHub Pages ni localStorage.

Generic REST puede declararse para routing/capabilities, pero imagen/video no se marca como ejecutable hasta implementar y probar un adapter real. La generación cloud del gateway tampoco se simula.

7. Fichas

Importa HTML/JSON/TXT del Geómetra o Content Creator. Vision detecta prompts embebidos y prepara cambios sin ejecutar el HTML importado.

  1. Importa una o varias fichas.
  2. Revisa slots detectados, asset/contexto y prompt actual.
  3. Mejora manualmente o con Vision.
  4. Compara before/after.
  5. Aplica únicamente patches aprobados.
  6. Exporta una copia actualizada conservando el lienzo.

8. XRoll, Storyboard y Carousel

XRoll

2–8 layers

Master prompt, prompts independientes por capa, motion, parallax, composite spec y handoff. Vision planea; XRollsArchitect será la app especializada de composición avanzada.

Narrative

Storyboard / Carousel

Storyboard mantiene film grammar, escena, shot y continuidad. Carousel mantiene tesis → hook → contexto → progresión → mecanismo → payoff y prompts por slide.
